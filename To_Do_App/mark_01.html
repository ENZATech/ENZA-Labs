1. How to Run This on Your PC Every Day (No React/Node Needed!)

  1. Save this code on your PC as ritual_todo_app.html (on your Desktop or Documents folder).
  2. Double-click ritual_todo_app.html to open it in Chrome, Edge, or Brave.
  3. Make it a standalone PC App Icon: In Edge or Chrome, click the 3-dot menu (⋮) → Apps / Save and Share → Install Page as App... (or Create Shortcut → Open as Window). Pin it to your Windows Taskbar!
  4. Your Data Stays Saved: Every check-in, subtask step, note, and streak is saved automatically in your browser's localStorage. You can also click Backup (.json) in the header anytime to save a physical file on your hard drive.

2. Since You Know C & HTML: Build Your Own `.exe` Launcher in C!

Want a native Windows .exe program written in C that opens your Habit & To-Do Dashboard in a dedicated frameless app window? Compile this 12-line C program with GCC (gcc launcher.c -o RitualApp.exe): 

#include <stdlib.h>
#include <stdio.h>

int main() {
    printf("Launching Ritual To-Do & Habit Dashboard...\n");
    // Opens ritual_todo_app.html in Edge/Chrome App Mode (no browser tabs/address bar!)
    system("start msedge --app=\"%cd%\\ritual_todo_app.html\"");
    return 0;
}
