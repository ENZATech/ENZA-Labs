💻 Run as a Native PC App + C `.exe` Launcher

Option 1: Install as a Standalone Desktop Window (Edge / Chrome)

Open this `.html` file in Chrome or Edge → click the three dots (`⋮`) → Apps / Save and Share → Install Page as App / Create Shortcut (Open as Window). Pin it to your Windows taskbar!

Option 2: Compile Your Own Native C `.exe` Desktop Launcher

Save this C code as launcher.c in the same folder and compile with gcc launcher.c -o RitualOS.exe -mwindows:

#include <stdlib.h>
int main() {
    system("start msedge --app=\"file:///%CD%/ritual_todo_app.html\"");
    return 0;
}
